This button combines HTML5 Canvas 2D matrix rendering with CSS 3D Spring Physics:

  • Illumination Matrix: Cursor proximity dynamically lights up surrounding mosaic tiles into cyan and baby blue hues.
  • Elastic Push-Back: Calculates continuous Euler tilt (X, Y) and Z-axis depression with damped spring physics to mimic physical mass.
  • Wave Propagation: Multi-layered circular wavefronts with exponential decay create the aquatic shockwave upon click.
